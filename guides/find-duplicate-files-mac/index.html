How to find duplicate files on a Mac

By Little Mac Apps · Updated October 5, 2026

Short answer: macOS has no general duplicate-file finder. For photos and videos, open Photos and click Duplicates under Utilities in the sidebar (macOS Ventura or later). For everything else, use a tool that compares file contents. File Stacker's Duplicates tool (Pro) groups identical files, lets you choose which copy to keep, and moves the others to the Trash.

Identical files vs. similar files

“Duplicate” can mean two different things, and they need different tools.

KindWhat it meansExample
IdenticalThe files contain exactly the same bytes, even if their names, dates or folders differ.An installer downloaded twice; report.pdf and report (1).pdf.
SimilarThe files look alike but their contents differ.A photo and its edited or resized version; two burst shots; a song in two formats.

Identical files contain the same bytes, but their locations and metadata can matter. Before removing a copy, check that no app or project depends on it and that you’ve kept the metadata you need. Similar files need a person to compare them. File Stacker's Duplicates tool finds identical files only. It doesn't decide whether two different photos look alike.

What macOS can do on its own

Photos library: the Duplicates collection

  1. Open Photos and click Duplicates under Utilities in the sidebar. If you don't see it, Photos may not have found any yet.
  2. Select the duplicates you want to combine and click Merge.
  3. One item stays in your library. The others move to Recently Deleted, where you can recover them for 30 days.

Never delete files from inside the Photos library package in Finder. Use Photos for anything in your library.

Other files: a manual check in Finder

Finder can't compare contents, but it can show likely duplicates. Search for a name, then switch to list view and sort by Size. Files with the same name and exactly the same size are worth checking. Open both before deleting, because the same size doesn't prove the same contents.

Find identical files with File Stacker PRO

Scanning and the treemap are free. The Duplicates tool needs the one-time Pro unlock.

  1. Scan the folders you want to check. Your Home folder is a good start; add an external disk with Grant Access to a Folder….
  2. Open Duplicates in the sidebar.
  3. Choose Ignore files under 1 MB, 10 MB or 100 MB. Larger limits are faster and show where the space is.
  4. Click Find Duplicates. Each set lists copies with identical contents, with the size of one copy and how many there are.
  5. Choose which copy to keep with the Keep menu (Newest copy, Oldest copy or a folder), or click Keep this one on a specific copy.
  6. Click the set's button to keep that copy and move the others to the Trash. File Stacker checks every copy again right before anything moves.

To check a file before choosing, select it to see its full path and dates, or press Space for Quick Look (macOS 14 or later).

How to choose which copy to keep

  • Keep the copy in the place you'd look for it. A file in an organized project or Documents folder is usually the one to keep. A copy in Downloads or on the Desktop is usually the spare.
  • Keep the copy an app depends on. Files inside a project folder, a code repository or an app's own folder may be referenced by path. Deleting that copy can break the project even though another copy exists.
  • Think about synced folders. Deleting a copy in iCloud Drive or another synced folder removes it from your other devices too.
  • Newest isn't always best. Identical files have the same bytes, so “newest” only means the most recently modified copy on disk. Choose by location and dependencies, not by date alone.
  • Keep the metadata you need. Finder tags, comments, the file name and dates aren't part of the contents, so two identical files can carry different ones. Copy anything you want onto the copy you keep before removing the others.

Why removing a duplicate may free less space than shown

File Stacker treats duplicate savings as an upper bound. You may get back less than the size shown because:

  • APFS clones share storage. When you copy a file on the same APFS volume, macOS can create a clone that shares the original's data blocks. Deleting a clone frees almost nothing. File Stacker marks these sets as APFS clones.
  • Hard links point to the same data. Two paths can refer to one file on disk, so removing one path frees nothing.
  • Compression and sparse files mean a file can take up less space on disk than its listed size.
  • The Trash still holds the file. The space isn't available until you empty the Trash. File Stacker never empties it for you.

Files stored only in iCloud are skipped rather than downloaded to compare.

Undoing a mistake

Everything File Stacker removes goes to the Trash. Open Recent Removals and click Put Back to return an item to its original folder, as long as it's still in the Trash. In Finder, you can also select an item in the Trash and choose File → Put Back. You can also mark a folder Protect from removal so no tool ever suggests files inside it.
